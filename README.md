# OSV5M Geolocation and Confidence Benchmark

This project evaluates street-level image geolocation with the OSV5M baseline model. It includes:

- baseline geolocation inference;
- image corruption benchmarks for blur, JPEG compression, noise, resize, crop, low light, and fog;
- confidence features and abstention analysis;
- calibration subsets and ablation studies;
- a Flask web demo for prediction and uncertainty visualization.

The project uses paths relative to the repository. The raw OSV5M dataset and model weights are downloaded separately because they are too large for a normal GitHub repository.

## Requirements

- Python 3.10 or newer
- Git
- A GPU is recommended for inference, but CPU inference is possible with a smaller batch size
- Enough disk space for the OSV5M data and model cache

## Installation

Clone the repository and enter its directory:

```bash
git clone <YOUR_REPOSITORY_URL>
cd myproject
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Activate it on Linux or macOS:

```bash
source .venv/bin/activate
```

Install the dependencies:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

The default model is `osv5m/baseline` and is downloaded automatically from Hugging Face on first use. To use a local model directory instead:

```powershell
$env:OSV5M_BASELINE = "D:\models\osv5m-baseline"
```

## Dataset setup

Download the OSV5M dataset according to its official instructions. The configured dataset directory must have this structure:

```text
data/osv5m/
  test.csv
  train.csv
  images/
    test/extracted/
    train/extracted/
```

The default location is `data/osv5m`. For a dataset stored elsewhere, set `OSV5M_DATA_DIR` before running a script:

```powershell
$env:OSV5M_DATA_DIR = "D:\datasets\osv5m"
```

The dataset is not included in this repository.

## Reproduce the benchmark

Run commands from the repository root:

```bash
python codes/prepare_subset.py
python codes/run_baseline.py
python codes/evaluate.py
python codes/run_corruption_benchmark.py
python codes/run_full_benchmark_with_confidence.py
python codes/train_abstention.py
python codes/ablation_study.py
```

Calibration workflows are available through:

```bash
python codes/prepare_subset_calib.py
python codes/prepare_subset_changed_to_train.py
python codes/run_with_confidence_calib_test.py
python codes/run_with_confidence_changed_to_train.py
```

Generated CSV files and corrupted image examples are written under `results/`. They are intentionally ignored by Git; they can be regenerated with the commands above.

## Run the web demo

The demo expects the trained abstention model and confidence CSV generated by the benchmark commands. Start it from the repository root:

```bash
python demo/app.py
```

Open <http://127.0.0.1:5000> in a browser.

The demo accepts an uploaded image, returns predicted latitude and longitude, calculates confidence features, and can evaluate the configured corruption variants. If the uploaded filename matches an image in `datasets/subset_test`, the demo also displays the available ground truth comparison.

## Repository layout

```text
codes/       Benchmark, inference, calibration, and shared path modules
data/        Local OSV5M data directory; ignored by Git
datasets/    Small metadata files and generated subset images
demo/        Flask API and browser interface
results/     Generated predictions and analysis outputs; ignored by Git
```

The upstream OSV5M implementation is kept under `codes/github-osv5m/osv5m`. Its original license and README remain in that directory.

## Reproducibility notes

- Set `OSV5M_DATA_DIR` and, when needed, `OSV5M_BASELINE` instead of editing source files.
- Run scripts from the repository root so Python imports and relative notebook paths behave consistently.
- The project does not commit model weights, raw OSV5M images, generated results, or local credentials.
